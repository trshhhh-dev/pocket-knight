pocket-knight is a 4 KB pure-stdlib Python chess engine for the make.fun tiny-chess-01 bounty: a mailbox board with incremental material+PST evaluation and Zobrist hashing, and an alpha-beta search with PVS, iterative deepening, a transposition table, MVV-LVA ordering, killer moves, null-move pruning, check extensions, quiescence search and repetition detection, all under a deterministic node budget.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
